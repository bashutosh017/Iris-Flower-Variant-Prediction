# Iris Flower Variant Prediction

## Project Overview:
The project demonostrates a **Machine Learning classfication model** using the famous ***Iris Flower Dataset*** and __Scikit-Learn__ library. The goal of the model is determine the flower species from the major know species __Setosa__,__Versicolor__or __Virginica__-based on the measurements of flower.

## Features:
- __Load__ the Iris dataset from __Scikit-Learn__.
- __Explore__ dataset features and target classes.
- __Split__ data into traing and testing sets.
- __Tarin__ a machine learning classifier model.
- **Evalute** model accuracy and perfomance using __accuracy score__.
- **Predict** the species of the new flower sample.

## Technologies Used:
- Python
- Scikit-Learn
- Numpy
- Pandas
- Streamlit
- FastAPI

## Dataset:
The Iris dataset contains **150 flower samples** with __4 input features__:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

__Target Classes:__
- Setosa
- Versicolor
- Virginica
